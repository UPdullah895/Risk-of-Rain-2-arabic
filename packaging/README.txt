Risk of Rain 2 - تعريب كامل للعبة
Risk of Rain 2 - Arabic translation
================================================================

ما هذا / What this is
----------------------------------------------------------------
تعريب للعبة Risk of Rain 2 يُركَّب كإضافة (mod) عبر BepInEx. لا
يُعدَّل أي ملف من ملفات اللعبة: حذف مجلد الإضافة يعيد اللعبة كما
كانت تمامًا.

An Arabic translation of Risk of Rain 2, delivered as a BepInEx
plugin. No game file is modified - deleting the mod folder puts
the game back exactly as it was.


اللعب الجماعي / Multiplayer
----------------------------------------------------------------
التعريب لا يؤثر على اللعب الجماعي. فهو لا يرفع علامة "معدَّلة"
عن اللعبة، ولذلك تبقى في نفس قوائم المضيفين مع اللاعبين الآخرين،
وتبقى التحديات الموسمية (Prismatic Trials) تعمل.

The translation does not affect multiplayer. It never sets the
game's "modded" flag, so you stay in the same lobby pool as
everyone else and Prismatic Trials keep working.


قبل التركيب / Before you install
----------------------------------------------------------------
يلزم تثبيت BepInEx 5.4.21 (نسخة x64) في مجلد اللعبة أولًا:
https://github.com/BepInEx/BepInEx/releases
فك ضغط الملف داخل مجلد اللعبة بحيث يصير مجلد BepInEx بجوار
Risk of Rain 2.exe، ثم شغّل اللعبة مرة واحدة وأغلقها.

BepInEx 5.4.21 (the x64 build) must be installed in the game
folder first. Unzip it so that BepInEx/ sits next to
Risk of Rain 2.exe, run the game once, then close it.

إن كنت تستعمل r2modman أو Thunderstore Mod Manager فإن BepInEx
موجود مسبقًا داخل مجلد الملف الشخصي (profile)، ووجّه المثبّت
إلى ذلك المجلد.

If you use r2modman or Thunderstore Mod Manager, BepInEx is
already inside the profile folder - point the installer there.


التركيب على ويندوز / Installing on Windows
----------------------------------------------------------------
انقر نقرًا مزدوجًا على install-windows.bat
سيبحث المثبّت عن اللعبة وحده. إن لم يجدها اضغط "استعراض..."
وحدّد المجلد الذي يحتوي على Risk of Rain 2.exe

Double-click install-windows.bat
It finds the game by itself. If it cannot, click Browse and pick
the folder that has Risk of Rain 2.exe in it.

إن ظهرت رسالة عن الصلاحيات، شغّل الملف بزر الفأرة الأيمن ثم
"تشغيل كمسؤول".
If it reports a permissions problem, right-click the file and
choose Run as administrator.


التركيب على لينكس / Installing on Linux
----------------------------------------------------------------
    ./install.sh

ولتحديد مسار اللعبة يدويًا / to give the path yourself:

    ./install.sh "/path/to/Risk of Rain 2"


تشغيل التعريب / Turning it on
----------------------------------------------------------------
شغّل اللعبة، افتح الإعدادات، واختر "العربية" من قائمة اللغات.
اختر اللغة من داخل اللعبة لا من ملف الإعدادات: اللعبة تحفظ
اللغة في Steam Cloud وتستعيدها فوق أي تعديل يدوي.

Start the game, open Settings, and choose العربية in the
language list. Pick it in-game rather than by editing config.cfg:
the game stores the language in Steam Cloud and restores it over
any hand edit.


الإزالة / Removing it
----------------------------------------------------------------
ويندوز: شغّل install-windows.bat واضغط "إزالة".
لينكس:  ./install.sh --uninstall

Windows: run install-windows.bat and click إزالة (Uninstall).
Linux:   ./install.sh --uninstall


ما لم يُعرَّب / What is left in English
----------------------------------------------------------------
أسماء صنّاع اللعبة في قائمة الشكر، ونصوص المحرّك والتراخيص،
وبعض مداخل السجلّ الخاصة بالأغراض. وهذه مقصودة.

The credits (they are people's names), the engine and legal
strings, and some item logbook entries. That is deliberate.
